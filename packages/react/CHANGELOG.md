# @codepom/react

## 2.3.0

### Minor Changes

- e632187: Add one type scale for every page, modelled on codepom.io's MVP Build page.

  - **@codepom/tokens:** `--pom-type-{page,title,item,stat,lead,body,small,label,caption,mono}-*` tokens (size, leading, tracking, weight), and matching Tailwind `text-{role}` font sizes in the preset (`text-page`, `text-caption`, …).
  - **@codepom/react:** `Heading` (`level` 1–6; role defaults by level: page / title / item; `size` and `tone` override), `Text` (`lead`, `body`, `small`, `caption`, `mono`, `stat`) and `Eyebrow` (monospace uppercase kicker, `md` / `sm`). Tones: default, secondary, tertiary, accent, inherit. Also available as `.pom-text--{role}` classes.

## 2.2.0

### Minor Changes

- 2b033e4: Add `Accordion`, `Chip` / `ChipGroup` and `Carousel`; `Card` passes through HTML attributes.

  - **`Accordion`** — accessible disclosure list (`button` + `region`, heading level configurable), one-at-a-time or `multiple`, controlled or uncontrolled, `numbered` titles, `chevron` or rotating `plus` icon, Arrow/Home/End focus movement, `onToggle(id, open, index)` for analytics. Height animates in CSS (no measuring) and closed panels are hidden from assistive tech.
  - **`Chip`** — compact toggle button (`aria-pressed`). **`ChipGroup`** — single-select is a radio group (one tab stop, arrow keys move the choice, disabled options skipped); `multiple` is a group of toggle buttons; `invalid` marks a missing required choice.
  - **`Carousel`** — scroll-snap track with prev/next, dots, arrow-key navigation and labelled slides. With `controls="auto"` (default) the controls only render while slides overflow. Size slides and spacing with `--pom-carousel-slide-size`, `--pom-carousel-gap`, `--pom-carousel-controls-inset` and `--pom-carousel-control-offset`.
  - **`Card`** now forwards standard HTML attributes (`style`, `id`, `data-*`, …); `style` was previously dropped silently.
  - Blueprint theme covers all three (larger accordion titles, square mono chips).

## 2.1.0

### Minor Changes

- 0516552: Fix component styling and add what codepom.io needs to drop its local overrides.

  **@codepom/react**

  - **Fix:** `styles.css` now styles every class the components emit. Components had moved to BEM names (`pom-btn--primary`, `pom-card__header`, …) but the stylesheet still used the old single-dash names, so most components rendered unstyled. A contract test now fails the build if a component emits a class the stylesheet doesn't define.
  - **Fix:** `Checkbox`, `Radio` and `Toggle` no longer depend on Tailwind utility classes being generated by the consumer; they use `pom-` classes. `Toggle` now exposes `role="switch"`.
  - **New:** `themes/blueprint.css` — opt-in sharp/dashed/monospace theme, enabled with `data-pom-theme="blueprint"` on any ancestor.
  - **New:** `Button` renders an `<a>` when given `href` (disabled links are `aria-disabled` and unfocusable), adds an `outline` variant, and marks icon side with `pom-btn__icon--left|right`.
  - **New:** `Navbar` supports `menus` (desktop mega panels with an optional feature card), a mobile drawer with drill-down screens, focus management, Escape/outside-click handling, i18n `labels`, `mobileLogo`/`mobileFooter`, `getLinkProps` for analytics attributes, and `onMenuOpen(menu, source, via)`/`onMobileOpenChange` callbacks (`via` is `hover` or `click`, so analytics can ignore hover-opens). A panel opened by hover is no longer closed by the click that follows.
  - Storybook now loads the real stylesheets and has a theme switcher.

  **@codepom/tokens**

  - **Fix:** the Tailwind preset is now a real ES module (`export default`); importing it from an ESM config failed before.
  - Preset `borderRadius` and `boxShadow` read the CSS variables, so themes reach Tailwind utilities.
  - New tokens: `--pom-border-strong`, `--pom-surface-hover`, `--pom-primary-hover`, `--pom-primary-tint`, `--pom-accent-tint`, z-index layers, and theme knobs `--pom-border-style`, `--pom-font-label`, `--pom-label-transform`, `--pom-label-tracking`.
